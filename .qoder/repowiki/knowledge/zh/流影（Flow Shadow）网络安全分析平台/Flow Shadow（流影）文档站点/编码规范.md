- 文档按功能分节组织在 `content/zh/<section>/_index.md` 下，每节以 `_index.md` 作为章节首页，子页面直接放在同目录下。
- 站点配置采用分层 TOML：`config/_default/` 存放通用配置，`config/production/` 与 `config/development/` 按环境覆盖参数。
- 模板覆盖遵循 Hugo 主题覆盖约定：根 `layouts/` 下的同名文件覆盖 `_vendor/.../gohugoioTheme/layouts/` 中的对应模板。
- 可复用 UI 片段统一放入 `layouts/partials/` 并按语义子目录组织（如 `home-page-sections/`、`opengraph/`、`svg/`）。
- Markdown 中通过 `layouts/shortcodes/` 自定义短代码（如 note、tip、warning、code、gh 等）来增强文档表达。
- 站点级元数据集中放在 `data/*.toml` 或 `data/docs.json` 中，由模板通过 `site.Data` 读取，避免硬编码到模板。
