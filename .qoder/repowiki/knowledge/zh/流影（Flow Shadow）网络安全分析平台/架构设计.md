根目录聚合四个职责分明的子系统：ly_analyser 负责基于 NetFlow v9 的流量扫描与威胁建模，产出事件/特征/取证数据；ly_server 作为管理后端提供 HTTP CGI 接口、配置下发与数据库持久化，并复用 ly_analyser 的 src/common 中的 .proto 定义（event.proto、feature.proto、evidence.proto、policy.proto、config.proto 等）作为跨进程契约；ly_vis 是 React+Ant Design 前端，通过调用 ly_server 暴露的 REST/CGI 接口进行可视化展示；ly_docs 使用 Hugo 构建项目文档站点。各子模块通过 protobuf 消息与 HTTP 协议解耦，无直接代码依赖，由部署编排（如脚本或容器）串联启动顺序：ly_analyser → ly_server → ly_vis。
