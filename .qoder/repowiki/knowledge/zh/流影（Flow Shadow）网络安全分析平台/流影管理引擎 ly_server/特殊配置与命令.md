依赖环境位于 `dependence/` 下的 tar 包（cgicc-3.2.16、cppdb-0.3.1、protobuf-3.8.0、db.server.v1.1.231123.sql）。构建顺序必须为 `cd src/common && make install` → `cd ../lib && make install` → `cd ../server && make install`，产物分别安装到 `/Server/lib`、`/Server/www/d`、`/Server/bin`。运行前需创建 `/Server/etc/gl.server.cnf` 指向 MariaDB 的 `server` 库，并通过 cron 每 5 分钟执行 `/Server/bin/config_pusher` 与 `/Server/bin/gen_event`。
