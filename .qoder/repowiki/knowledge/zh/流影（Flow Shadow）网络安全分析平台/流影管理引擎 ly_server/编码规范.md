- 每个业务功能以独立 C++ 源文件组织，并在 `src/server/Makefile` 中声明为 `WWW_EXES` 或 `BIN_EXES` 条目，最终编译为同名 CGI 可执行文件。
- 跨进程/跨模块数据结构统一通过 `.proto` 文件定义并由 `protoc --cpp_out=.` 生成，请求与响应类型成对出现（如 `*_req.*` 与 `*.pb.*`）。
- 数据库访问集中封装在 `src/server/dbc.{h,cpp}`，业务代码通过 cppdb session 执行 SQL 字符串，避免直接散落的连接逻辑。
- 配置加载按类型拆分为 `config_*.so` 动态库，共享基类 `config_class.cpp` 定义统一接口，便于运行时按需装载。
- 日志输出统一通过 `common/log.h` 提供的 `log_info`/`log_err` 宏，错误路径捕获 `std::exception` 后记录并返回。
- 构建脚本通过 `-include local_debug.mk` 支持本地调试覆盖，各层 Makefile 结构一致（INCS/CXXFLAGS/LDLIBS/SRCS/OBJS 分离）。
